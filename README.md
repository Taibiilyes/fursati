# فرصتي — منصة عروض العمل والترشح المباشر

تطبيق ويب متكامل: التسجيل بالسيرة الذاتية، بحث تلقائي دوري عن العروض الجديدة وفلترتها لكل مستخدم، ترشح مباشر عبر بريد الموارد البشرية الرسمي، وتذكير آلي للمتابعة.

## ✨ الميزات

| الميزة | الوصف |
|---|---|
| 📄 **التسجيل بالسيرة الذاتية** | استخراج كامل آلي: الصورة الشخصية، الاسم، البريد، الهاتف، المسمى، الخبرات، الدبلومات، المهارات واللغات |
| 🔄 **بحث تلقائي كل 12 ساعة** | حلقة خلفية تفحص العروض الجديدة دورياً، تفلترها لكل مستخدم (حد مطابقة 55%+) وتضيف «فرص مقترحة» جاهزة للترشح الفوري دون العودة لصاحب الحساب — مع إمكانية «بحث الآن» الفوري |
| 🎯 **بحث متعدد** | حسب الولاية، الاختصاص (37 اختصاصاً)، الكلمات المفتاحية، نوع العقد، **القرب الجغرافي من عنوان الإقامة** (Haversine كم)، أو الترتيب حسب مطابقة السيرة |
| 📬 **بريد توظيف رسمي** | كل عرض يحمل بريد موارد بشرية مخصص (recrutement@ / carriere@) مع زر نسخ وفتح البريد بنص جاهز |
| ✨ **تخصيص آلي PDF + Word** | سيرة ورسالة تحفيزية (عربية/فرنسية) لكل منصب، بخطوط Tajawal/Amiri وصورة المترشح |
| ⏰ **تذكير تلقائي بعد أسبوع** | عند مضي 7 أيام على أي ترشح مُرسل، يحرّر النظام رسالة متابعة + PDF + رابط بريد جاهز تلقائياً (مع زر محاكاة للتجربة) |
| 🗂️ **سجل نشاط دائم** | حفظ كل العمليات الناجحة: إنشاء الحساب، التعديلات، التوليدات، الإرسالات، التذكيرات، دورات البحث |
| ➕ **إضافة من اللوحة** | مهارات، دبلومات، شهادات عمل، اهتمامات، خبرات — تُحفظ فوراً وتُعيد فلترة الفرص |
| 🧭 **تنقل سهل** | شريط علوي ثابت بشارات عدّادة + شريط سفلي بأسلوب التطبيقات على الهاتف |
| 📲 **تطبيق هاتف (PWA)** | قابل للتثبيت على الشاشة الرئيسية (Android/iOS) بأيقونة خاصة، وضع تطبيق مستقل، وعمل جزئي دون اتصال (Service Worker) |
| 🚀 **إرسال مباشر عبر SMTP API** | اربط بريدك (Gmail/Outlook/Office365/مخصص بكلمة مرور التطبيقات) — ويرسل التطبيق طلب الترشح مباشرة إلى بريد الموارد البشرية مع إرفاق السيرة والرسالة PDF آلياً، وكذلك تذكيرات المتابعة، مع اختبار اتصال وترجمة أخطاء عربية |

## 🚀 التشغيل

```bash
cd south-jobs
pip install flask python-docx pymupdf pillow
python app.py     # يفتح على http://localhost:5000
```

## 🧪 حساب تجريبي جاهز

- البريد: `amine.final2@example.dz` — كلمة المرور: `123456`
- فيه طلب ترشح مُرسل + تذكير متابعة جاهز + فرص مقترحة — جرّب زر «محاكاة مرور أسبوع» في صفحة التذكيرات.

## 🏗️ البنية

```
south-jobs/
├── app.py            # خادم Flask وكل المسارات
├── scheduler.py      # المحرك التلقائي: بحث كل 12 ساعة + تذكيرات الأسبوع
├── mailer.py         # الإرسال المباشر SMTP مع المرفقات وترجمة الأخطاء بالعربية
├── static/manifest.json + sw.js + icons/  # تطبيق الهاتف PWA
├── db.py             # SQLite: مستخدمون، عروض، فرص مقترحة، تذكيرات، سجل نشاط
├── cvparser.py       # محلل السيرة الذاتية (DOCX/PDF + استخراج الصورة)
├── matcher.py        # 37 مهارة (عربي/فرنسي/إنجليزي) + مطابقة + مسافات جغرافية
├── tailor.py         # مولّد Word (DOCX RTL)
├── pdfgen.py         # مولّد PDF فاخر (Tajawal/Amiri + تشكيل عربي كامل)
├── static/fonts/     # الخطوط المضمنة
└── previews/         # لقطات صفحات المنصة
```

## 📝 ملاحظات

- بيانات العروض استعراضية واقعية (شركات معروفة تعمل فعلاً في الجزائر) وتُستبدل بسهولة بعروض حقيقية في `db.py` — ويكفي جدول `POOL_JOBS` لمحاكاة وصول عروض جديدة كل دورة بحث.
- الإرسال عبر تطبيق بريد المستخدم (mailto) مع موضوع ونص جاهزين؛ تُرفق الملفات يدوياً لأن المتصفحات تمنع الإرفاق التلقائي.
